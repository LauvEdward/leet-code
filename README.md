# leet-code

Sổ tay luyện LeetCode bằng Swift: mỗi bài có lời giải, cơ sở lý thuyết, hướng xử lý và ý tưởng triển khai.

Trang web: https://lauvedward.github.io/leet-code/

## Cấu trúc

- `problems/` — các bài thuật toán, mỗi bài một thư mục (`Solution.swift`, `main.swift` để test, `notes.md` ghi chú).
- `concurrency/` — các bài mục Concurrency, cùng cấu trúc.
- `template.html` + `build.py` — sinh ra `index.html`.
- `run_tests.sh` — biên dịch và chạy test.

```bash
./run_tests.sh
python3 build.py
```
